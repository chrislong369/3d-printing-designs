# LongWorks 3D — Codex Project Instructions

For any 3D-printing, STL, 3MF, Blender, CAD, Bambu Studio, AMS, mesh-repair, or image-to-3D task:

1. Read `3D_PRINTING_CONTEXT.md`.
2. Read `TOOLCHAIN_CATALOG.md` before choosing tools.
3. Use `.codex/skills/3d-print-production/SKILL.md`.
4. Use the strongest specialist route for the job; do not default to primitive scripted geometry.
5. A concept image is a visual target, not a printable mesh.
6. Never call a job complete until the REAL mesh is validated and the final Bambu project is checked.
7. AMS is available. Do not assume AMS or no-AMS; choose based on the specific job unless the user explicitly specifies a strategy.
