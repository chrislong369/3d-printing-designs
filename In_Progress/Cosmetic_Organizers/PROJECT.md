# Cosmetic Organizers — Project State

## Purpose
This folder contains active LongWorks cosmetic organizer/display work. It includes multiple historical variants that are not automatically interchangeable.

## Current operating rule
- Treat measurements and current user-approved requirements as authoritative over filenames.
- Do not assume a file named `production`, `final`, `special`, `centered`, or a higher version number is the keeper.
- Do not delete nonidentical variants until the proven keeper is identified or the unique geometry/settings are reviewed.
- When a specific organizer/display is actively revised, record its exact target dimensions and required features here before finalizing it.
- New approved keeper exports should be clearly identified here, then moved/copied to `Final_Products/Cosmetic_Organizers/` only after validation.

## Current known families
- brow / brow-liner / pen holders
- mascara inventory trays
- compartment trays
- retail display variants

## Required finish path
Requirements/measurements → CAD/mesh update → deterministic geometry checks → Bambu Studio open/inspection → keeper identified → final export.

## Validation status
Existing files in this folder are IN PROGRESS unless separately documented as validated. Filename alone is not production evidence.

## Cleanup note
The repository-wide cleanup audit intentionally retained uncertain variants in this family. Use `docs/cleanup-review.md` before retiring older files.
